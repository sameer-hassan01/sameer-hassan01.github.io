Hisaab / Qeemat App

Personal finance & receipt manager for Pakistan · solo project
2026

A free, offline-first personal finance app built for Pakistani users. Combines receipt scanning (on-device OCR), expense and income tracking, smart insights, budgets, subscriptions, grocery price comparison, and a rewards system — with a Flutter mobile app, Node/Postgres API, and React admin panel. Deployed end-to-end on free-tier infrastructure (zero monthly cost).

Flutter Riverpod Node.js Express PostgreSQL Firebase Auth ML Kit OCR Cloudinary React Tailwind
  • Solo-designed 3 coordinated codebases: Flutter mobile, Node/Express REST API, React admin panel
  • On-device OCR via Google ML Kit; auto-categorization and duplicate detection
  • Offline-first with Hive cache + background sync queue
  • JWT-backed sessions, Firebase ID-token verification, Helmet + rate-limit + validator on every route
  • Deployed entirely on free tiers: Render, Neon, Cloudinary, Vercel, Firebase
